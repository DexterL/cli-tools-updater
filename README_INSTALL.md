# upcli macOS Intel release

1. Extract this archive.
2. Run `./install.sh` to install `upcli` into `~/.local/bin`.
3. Ensure `~/.local/bin` is on `PATH`, then run `upcli --version` or `upcli`.

This binary is for macOS Intel (`darwin/amd64`). It coordinates the separately
installed `codex`, `claude`, and `agy` commands; those tools are not bundled.
